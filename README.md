# westbrookpage
Este projeto é uma página simples sobre o jogador de basquete Russell Westbrook. A página apresenta algumas informações sobre sua carreira, uma imagem do jogador e algumas interações utilizando JavaScript.
Entre as funcionalidades estão um botão de boas-vindas, um botão para alterar a cor do título e um campo para informar o nome do usuário e exibir uma mensagem personalizada.

Como executar
Baixe ou clone o repositório.
Abra a pasta do projeto.
Abra o arquivo index.html em qualquer navegador.
A página será carregada e as funcionalidades poderão ser utilizadas diretamente no navegador.
Arquivos
index.html — estrutura da página.
teste4.css — estilos e aparência da página.
teste6.js — funcionalidades e interações com JavaScript.
